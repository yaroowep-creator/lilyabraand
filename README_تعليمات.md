# lilya_brannd — ماذا تغيّر وماذا يجب فعله الآن

## الملفات في هذه الحزمة
- `index.html` — الموقع (المتجر)
- `admin.html` — لوحة التحكم
- `netlify/functions/create-noest-order.js` — دالة إرسال الطلبية المؤكدة إلى Noest Express
- `netlify.toml` — إعدادات نشر Netlify

## أهم التغييرات
1. **صور المنتجات بدون أي اشتراك مدفوع**: الصور تُضغَط تلقائيًا داخل المتصفح ثم تُحفظ مباشرة مع المنتج في Firestore (نفس الطريقة السابقة، لكن محسّنة) — لا حاجة لتفعيل Firebase Storage ولا لإدخال أي بطاقة بنكية. يمكنك رفع عدة صور لكل منتج (عادة حتى 8-10 صورة حسب جودتها)، وتظهر لك لوحة التحكم حجم الصور المستخدم لحظيًا حتى لا تتجاوزي الحد.
2. **فيديوهات متعددة لكل منتج**: يمكنك إضافة أكثر من رابط فيديو واحد.
3. **مكتب التوصيل يظهر تلقائيًا حسب الولاية**: عند اختيار الزبونة "توصيل إلى مكتب"، تظهر لها قائمة بمكاتب Noest في ولايتها (مأخوذة من الدليل الذي أرسلته)، لتختار الأقرب لبلديتها.
4. **صفحة "أسعار التوصيل"** في لوحة التحكم: تعديل سعر كل ولاية ينعكس فورًا في الموقع دون إعادة نشر.
5. **صفحة "الإحصائيات"**: عدد الطلبات والمبيعات اليوم / هذا الأسبوع / هذا الشهر + جدول يومي.
6. **الطلبية لا تصل إلى Noest تلقائيًا أبدًا**: كل طلبية جديدة تُحفظ بحالة "بانتظار التأكيد". من صفحة "الطلبات" في لوحة التحكم يمكنك:
   - "تأكيد فقط" — لتصنيفها كمؤكدة دون إرسالها لـ Noest.
   - "تأكيد وإرسال لـ Noest" — لإرسالها تلقائيًا عبر الدالة البرمجية (تحتاج ضبط خطوة واحدة، انظر أدناه).
   - "نسخ البيانات" — متاح دائمًا، لنسخ بيانات الطلبية ولصقها يدويًا في لوحة Noest إذا فضّلتِ ذلك.

## خطوات يجب عليك القيام بها بنفسك (لا يمكنني الوصول إلى حساباتك مباشرة)

### 1) نشر الملفات
- إمّا سحب/إفلات مجلد الموقع بالكامل في Netlify (نفس الطريقة التي استعملتِها من قبل)، أو رفعه إلى GitHub ثم ربط GitHub بـ Netlify.
- لم أتمكن من إنشاء مستودع GitHub جديد بنفسك تلقائيًا (لا تتوفر لدي صلاحية وصول لحسابك على GitHub)، لذلك حمّلي هذه الملفات وارفعيها بنفسك إلى نفس المستودع الحالي:
  https://github.com/z44105477-design/lilya-brand
  (استبدلي `index.html` و`admin.html` بالنسختين الجديدتين، وأضيفي مجلد `netlify` وملف `netlify.toml`).

### 2) ربط Noest Express (اختياري، للإرسال التلقائي)
- من إعدادات موقع Netlify: **Site settings → Environment variables** أضيفي:
  - `NOEST_API_TOKEN` = التوكن الخاص بحسابك في Noest
  - `NOEST_GUID` = الـ GUID الخاص بحسابك
- بعد الإضافة، أعيدي نشر الموقع (Trigger deploy) ليأخذ Netlify القيم الجديدة.
- بدون هذه الخطوة، زر "تأكيد وإرسال لـ Noest" سيُحوّل الطلبية تلقائيًا إلى "مؤكدة" مع رسالة توضح أن الإرسال التلقائي غير مفعّل بعد، وتبقى إمكانية "نسخ البيانات" متاحة دائمًا كحل بديل فوري.
